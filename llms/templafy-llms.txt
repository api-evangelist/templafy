# Templafy

> Templafy is an enterprise document-generation and content-enablement platform. Its Public API is a REST API for automating template and asset management (documents, images, PDFs, links, presentations, slides, slide elements, spreadsheets, text elements, email elements), maintaining data sources, and generating on-brand documents, presentations, spreadsheets, and text elements from templates.

Authentication is an API key sent as an HTTP bearer token; keys are created and scoped in the Templafy Admin Center. Errors are RFC 7807/9457 Problem Details with a traceId. Lists paginate with pageNumber/pageSize. The base URL is per-tenant: https://{tenantId}.api.templafy.com/v3.

## APIs
- [Templafy Public API v3 (Stable)](https://templafypublicapi.blob.core.windows.net/specifications/openapi-v3.json): Current stable OpenAPI 3.0 spec — 78 operations across spaces, libraries, folders, assets, and data sources.
- [Templafy Public API v4 (Preview)](https://templafypublicapi.blob.core.windows.net/specifications/openapi-v4.json): Preview OpenAPI 3.0 spec.
- [Swagger UI](https://api.templafy.com/): Interactive API reference (v1-v4 + unstable).
